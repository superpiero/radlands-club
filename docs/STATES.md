# Jak se na stole značí stavy karet

| Stav | Fyzicky by to bylo… | V digitální verzi |
|---|---|---|
| Připravená a použitelná | karta bez žetonů | tyrkysový pulzující okraj (jen ve tvém tahu, když na schopnost máš) |
| Nepřipravená | žeton na kartě | vybledlá karta + odznak přesýpacích hodin; najetím myši se ukáže důvod |
| Poškozená (přeživší) | otočená karta | karta pootočená o −7°, červená prasklina, razítko „POŠKOZEN“ |
| Poškozená (základna) | otočená karta | červená prasklina + razítko „POŠKOZENO“; Pevnost ukazuje zelené/červené dílky odolnosti |
| Zničená základna | otočená rubem | šedá, šrafovaná, razítko „ZNIČENO“ |
| Tulák | karta lícem dolů | tyrkysový rub s nápisem TULÁK |
| Krytá karta | – | malý zelený štít v rohu |
| Omráčený | – | fialový odznak s hvězdičkami |
| Nálož | – | červený blikající odznak „NÁLOŽ“ na základně |
| Uložená voda | – | modrý odznak s kapkou a počtem |
| Odkrytý sloupec (Zvěd) | – | červeně šrafovaný sloupec s nápisem „ODKRYTO“ |
| Bunkr nezranitelný | – | modrý odznak „NEZRANITELNÝ“ |
| Platný cíl volby | – | pulzující rámeček: červený = útok, zelený = pomoc, zlatý = výběr |
| Místo pro přeživšího | – | zlaté přerušované pole „SEM (vepředu/vzadu)“ |
| Fronta operací | 3 místa | 3 sloty vlevo; místo 1 je u základen a má zlatý okraj |
| Nájezd / Cisterna v zóně | karta v zóně | žetony vpravo; zašedlé = jsou ve hře / v ruce |
| Voda | kapky | kapky v liště hráče; plné = k utracení, prázdné = utracené, světlejší = voda navíc |
